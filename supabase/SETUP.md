# คู่มือเชื่อม Flow CRM กับ Supabase (ใช้งานจริง)

ใช้เวลาประมาณ 15 นาที ทำครั้งเดียว ไม่ต้องเขียนโค้ด

## ขั้นที่ 1 สร้างโปรเจกต์ Supabase
1. ไปที่ https://supabase.com แล้วสมัคร/เข้าสู่ระบบ (ใช้บัญชี GitHub หรืออีเมลก็ได้)
2. กด **New project**
   - Name: `flow-crm`
   - Database password: ตั้งรหัสยาว ๆ แล้ว **เก็บไว้ในที่ปลอดภัย** (ไม่ต้องใช้ในแอป แต่ต้องใช้ตอนกู้ข้อมูล)
   - Region: **Southeast Asia (Singapore)** เร็วที่สุดสำหรับไทย
   - Plan: Free
3. รอประมาณ 1–2 นาทีจนสถานะเป็น Active

## ขั้นที่ 2 สร้างตารางและสิทธิ์ (วาง SQL ครั้งเดียว)
1. เมนูซ้าย **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase/schema.sql` ในชุดนี้ คัดลอกทั้งหมดไปวาง
3. กด **Run** ต้องขึ้น "Success. No rows returned"
   - ถ้ารันซ้ำได้ ไม่มีผลเสีย
   - สิ่งที่สร้าง: ตาราง profiles / customers / visits / approvals / settings, กฎสิทธิ์ (เซลส์เห็นเฉพาะของตัวเอง ผู้จัดการเห็นทั้งทีม), ที่เก็บไฟล์ `attachments`, และ Realtime

## ขั้นที่ 3 สร้างบัญชีผู้ใช้ (ผู้ดูแล/CEO เป็นคนสร้าง ใช้ชื่อผู้ใช้ ไม่ต้องมีอีเมลจริง)

Supabase บังคับให้ทุกบัญชีมี "อีเมล" แต่ไม่จำเป็นต้องเป็นอีเมลจริง แอปจึงใช้ **ชื่อผู้ใช้ + โดเมนภายใน** แทน:
ผู้ใช้พิมพ์แค่ `admin` หรือ `somchai` ในแอป ระบบจะแปลงเป็น `admin@flowcrm.local` ให้เอง (โดเมนตั้งใน `config.js` ค่า `loginDomain`)
ชื่อผู้ใช้ใช้ได้เฉพาะตัวอักษรอังกฤษ ตัวเลข จุด และขีด (เช่น `somchai.k`)

1. **Authentication → Sign In / Providers → Email**: เปิด **Enable Email provider**, ปิด **Confirm email** → Save
2. หน้าเดียวกัน ส่วน User Signups: ปิด **Allow new users to sign up** → Save (พนักงานสมัครเองไม่ได้ ผู้ดูแลสร้างให้เท่านั้น)
3. **สร้างบัญชีผู้ดูแล**: Authentication → Users → **Add user → Create new user**
   - Email: `admin@flowcrm.local`
   - Password: รหัสผ่านตั้งต้นที่ได้รับแยกต่างหาก (ไม่เขียนไว้ในไฟล์นี้)
   - ติ๊ก **Auto Confirm User** → Create
   - เปิดแอป ใส่ชื่อผู้ใช้ `admin` + รหัสผ่าน กรอกชื่อ-รหัสพนักงานหนึ่งครั้ง → เป็น "เจ้าของ / CEO" อัตโนมัติเพราะเป็นคนแรก
4. **เพิ่มพนักงานแต่ละคน** ทำ 2 จุด
   - ในแอป: หลังบ้าน → เพิ่มพนักงาน → ใส่รหัสพนักงาน ชื่อ **ชื่อผู้ใช้** (เช่น `somchai`) แผนก ตำแหน่ง → สร้าง
   - ใน Supabase: Authentication → Users → Add user → Create new user → Email `somchai@flowcrm.local` + รหัสผ่านตั้งต้น ติ๊ก Auto Confirm User
   - แจ้งลิงก์แอป ชื่อผู้ใช้ และรหัสผ่านให้พนักงาน ล็อกอินครั้งแรกระบบจับคู่ชื่อผู้ใช้กับรหัสเชิญ → ใช้งานได้ทันที ไม่ต้องรออนุมัติ
5. **เปลี่ยน/ลืมรหัสผ่าน**
   - ผู้ใช้เปลี่ยนเองในแอป: ตั้งค่า (ไอคอนเฟือง) → **เปลี่ยนรหัสผ่าน**
   - ผู้ดูแลตั้งให้ (กรณีลืม): บัญชีแบบชื่อผู้ใช้รับอีเมลไม่ได้ ปุ่ม Reset password ในหน้า Users จึงใช้ไม่ได้ ให้ใช้ SQL Editor แทน
     ```sql
     update auth.users
     set encrypted_password = extensions.crypt('รหัสใหม่', extensions.gen_salt('bf')), updated_at = now()
     where email = 'somchai@flowcrm.local';
     ```

ทางเลือก: ถ้าอยากให้พนักงานสมัครเองแล้วผู้จัดการอนุมัติในแอป ให้เปิด Allow new users to sign up และตั้ง `selfSignup: true` ใน `config.js` พนักงานจะพิมพ์ชื่อผู้ใช้ที่ต้องการเองได้ และคำขอไปรอในหน้าหลังบ้าน

## ขั้นที่ 4 นำค่าเชื่อมต่อมาใส่ในแอป
1. เมนูซ้าย **Project Settings** (ไอคอนเฟือง) → **API**
2. คัดลอก 2 ค่านี้
   - **Project URL** (รูปแบบ `https://xxxxxxxx.supabase.co`)
   - **anon public** key (ขึ้นต้นด้วย `eyJ...` ยาวมาก)
   - **ห้าม**ใช้ `service_role` key ในแอปเด็ดขาด
3. เปิดไฟล์ `config.js` แล้ววางค่า
   ```js
   window.FLOW_SUPABASE = {
     url: 'https://xxxxxxxx.supabase.co',
     anonKey: 'eyJhbGciOi...',
     selfSignup: false,        // false = ผู้ดูแลสร้างบัญชีให้, true = พนักงานสมัครเองแล้วรออนุมัติ
     loginDomain: 'flowcrm.local'  // โดเมนภายในที่ต่อท้ายชื่อผู้ใช้
   };
   ```
4. อัปโหลด `index.html`, `config.js`, โฟลเดอร์ `assets/` ขึ้น GitHub Pages หรือโฮสต์ของบริษัท
   - anon key เปิดเผยได้ (ถูกออกแบบมาให้อยู่ในหน้าเว็บ) ความปลอดภัยมาจากกฎสิทธิ์ในฐานข้อมูล ไม่ใช่การซ่อนคีย์

## ขั้นที่ 5 เริ่มใช้งาน
1. เปิดแอปจาก URL ที่โฮสต์ไว้ → เข้าสู่ระบบด้วยชื่อผู้ใช้ `admin` ที่สร้างในขั้นที่ 3
2. **คนแรกที่ลงทะเบียนจะเป็น "เจ้าของ / CEO" โดยอัตโนมัติ** (เห็นทั้งทีม อนุมัติ จัดการผู้ใช้งานได้) ดังนั้นให้เจ้าของล็อกอินก่อนคนอื่น
3. ตั้งค่าบริษัท (ไอคอนเฟืองมุมขวาบน): พิกัดบริษัท อัตราเบิก เป้าหมาย
4. เพิ่มทีมตามขั้นที่ 3 ข้อ 4 (สร้างรหัสเชิญในแอป + สร้างบัญชีใน Supabase ด้วยชื่อผู้ใช้เดียวกัน)
5. ตั้งผู้จัดการเพิ่ม: หลังบ้าน → แตะชื่อ → ตำแหน่ง "ผู้จัดการฝ่ายขาย" → บันทึก (มีผลทันที)

## ดูแลระบบ
- **สำรองข้อมูล**: แพ็กเกจฟรีไม่มีสำรองอัตโนมัติ ให้กด "ส่งออก CSV" ในหน้าเบิกทุกสิ้นเดือน หรือ Dashboard → Database → Backups (เมื่อเป็น Pro)
- **โปรเจกต์พัก**: ถ้าไม่มีใครใช้ 7 วัน (แพ็กเกจฟรี) Supabase จะพักโปรเจกต์ เปิดใหม่ได้ที่ Dashboard กด Restore ใช้เวลาไม่กี่นาที ข้อมูลไม่หาย
- **ดูข้อมูลดิบ**: Dashboard → Table Editor เลือกตาราง `visits` (คอลัมน์ `data` เก็บรายละเอียดทั้งหมดของการเช็คอิน)
- **ลบผู้ใช้ถาวร** (รวมบัญชีอีเมล): Authentication → Users → เลือกคน → Delete user ส่วนในแอป "ลบผู้ใช้งาน" จะลบเฉพาะข้อมูลพนักงาน ถ้าคนนั้นล็อกอินอีกจะต้องลงทะเบียนใหม่และรออนุมัติ
- **ลืมรหัสผ่าน**: ผู้ดูแลตั้งรหัสใหม่ให้ด้วยคำสั่ง SQL ในขั้นที่ 3 ข้อ 5

## ใช้งานผ่านลิงก์ Claude ต่อได้ไหม
ได้ ลิงก์ Claude เดิมยังใช้ที่เก็บข้อมูลของ Claude ตามเดิม ส่วน `index.html` ที่โฮสต์เองจะใช้ Supabase ข้อมูลสองที่นี้แยกกัน แนะนำให้ทีมใช้ทางใดทางหนึ่ง
