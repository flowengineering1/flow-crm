# Flow CRM ภาคสนาม

เว็บแอป CRM ภาคสนามของ FLOW ENG สำหรับพนักงานขาย: เช็คอินเข้าพบลูกค้าด้วยพิกัด GPS ส่งรายงานหน้างานพร้อมรูป
คำนวณค่าเดินทางตามระยะทาง (ค่าเริ่มต้น 7 บาท/กม. ปรับได้) และให้ผู้จัดการฝ่ายขายตรวจและอนุมัติ ใช้ได้ทั้งมือถือและ PC

## โครงสร้าง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `flow-crm.html` | ซอร์สของหน้าแอป (ไม่มี `<html>/<head>` ครอบ) ใช้เผยแพร่เป็น Claude Artifact ซึ่งมีฐานข้อมูลกลางของทีมและระบบสิทธิ์ |
| `index.html` | ไฟล์เดียวกันครอบด้วยโครง HTML เต็ม เปิดได้จาก GitHub Pages หรือเว็บเซิร์ฟเวอร์ทั่วไป (โหมดนี้ข้อมูลเก็บในเครื่องผู้ใช้เท่านั้น) |
| `assets/flow-logo-1024.png` | โลโก้บริษัท |

ไม่มีขั้นตอน build แอปเป็น HTML/CSS/JS ไฟล์เดียว ไม่พึ่งไลบรารีภายนอก

## ฟีเจอร์หลัก

- **ลูกค้า**: รายชื่อ ผู้ติดต่อ ที่ตั้ง สถานะโอกาสขาย มูลค่า และงานที่ต้องติดตาม
- **เช็คอิน 4 ขั้น**: ลูกค้า → พิกัด GPS (หรือวางพิกัด/ลิงก์ Google Maps) → รายงานและรูป (สูงสุด 3 รูป) → ค่าเดินทาง
- **คำนวณค่าเดินทาง**: ระยะขาไป × 2 × อัตราต่อกิโลเมตร + ค่าทางด่วน/ที่จอดรถ; รถส่วนกลางเบิกตามใบเสร็จ
- **ตรวจสอบอัตโนมัติ**: เตือนเมื่อไม่มีรูป พิกัดใส่เอง เช็คอินห่างจากที่ตั้งลูกค้า หรือระยะที่เบิกสูงกว่าที่ระบบประมาณจากพิกัดบริษัท
- **อนุมัติ**: ผู้จัดการอนุมัติ/ตีกลับ พร้อมหมายเหตุ มีหน้าต่างยืนยันทุกปุ่มสำคัญ
- **รายงานรายเดือน**: ของเซลส์แต่ละคน และของทีมสำหรับผู้จัดการ (เทียบรายคน รายการที่ควรตรวจ งานค้าง ลูกค้าที่ขาดการติดต่อ)
- **ส่งออก CSV** ตามคอลัมน์ของแบบฟอร์มเบิกค่าน้ำมัน
- บันทึกการเข้าพบไว้ก่อนโดยยังไม่ขอเบิก แล้วกลับมากด "ขอเบิกค่าเดินทางย้อนหลัง" จากรายการนั้นได้
- แนบรูปหน้างานและไฟล์จากลูกค้า (PDF, Excel, แบบ DWG ฯลฯ) ได้สูงสุด 10 ไฟล์ต่อการเช็คอิน รูปย่ออัตโนมัติ ไฟล์อื่นไม่เกิน 3 MB
- "สิ่งที่ต้องทำต่อ" เป็น dropdown แบ่ง 5 หมวด (เอกสาร/เทคนิค, ตัวอย่าง/ทดสอบ, ประสานงาน/เจรจา, ปิดการขาย/ส่งมอบ, ดูแลความสัมพันธ์) เพิ่มตัวเลือกเองได้ถ้าไม่มีในรายการ มีช่องหมายเหตุ และตั้งวันครบกำหนดให้อัตโนมัติตามหมวด
- ลงทะเบียนพนักงานขายใหม่: เซลส์ที่เปิดลิงก์ครั้งแรกกรอกชื่อ รหัส แผนก เบอร์โทร แล้วรอผู้จัดการอนุมัติ หรือใส่รหัสเชิญที่ผู้จัดการสร้างไว้เพื่อใช้งานทันที
- หน้า "หลังบ้าน" สำหรับเจ้าของ/CEO/ผู้จัดการ: ภาพรวม คำขอลงทะเบียน รายชื่อผู้ใช้งาน (แก้ไข ระงับ เปิดใช้ ลบ) รหัสเชิญ และกิจกรรมล่าสุด

## สิทธิ์การใช้งาน (โหมด Claude Artifact)

| บทบาท | สิทธิ์ใน Share menu | ทำอะไรได้ |
|---|---|---|
| ผู้จัดการฝ่ายขาย | Editor | ดูข้อมูลทั้งทีม อนุมัติ ตั้งอัตรา/พิกัดบริษัท/เป้าเข้าพบ |
| พนักงานขาย | Contributor | เช็คอิน ส่งรายงาน ดูรายการและยอดเบิกของตัวเอง |

การแยกข้อมูลรายคนบังคับที่ชั้นฐานข้อมูล (`visits/{self}`, `staff/{self}`) ไม่ใช่แค่ซ่อนบนหน้าจอ

## การตั้งค่าก่อนใช้จริง

1. ผู้จัดการกดปุ่มตั้งค่า ⚙ แล้ววางพิกัดของออฟฟิศ เพื่อให้ระบบประมาณระยะทางสำหรับตรวจสอบได้
2. ตรวจอัตราต่อกิโลเมตร (ค่าเริ่มต้น รถยนต์ 7, มอเตอร์ไซค์ 2.5) และเป้าเข้าพบต่อคนต่อเดือน (ค่าเริ่มต้น 40)
3. พนักงานแต่ละคนตั้งชื่อในหน้าตั้งค่าครั้งแรกที่เปิด

อ้างอิงระเบียบ: "ระเบียบและแบบฟอร์มการเบิกค่าเดินทาง ค่าน้ำมัน และระบบรายงานการเข้าพบลูกค้า" ของ FLOW ENG

## เชื่อมฐานข้อมูล Supabase (ใช้งานจริง)
อ่าน [supabase/SETUP.md](supabase/SETUP.md) ขั้นตอนโดยย่อ: สร้างโปรเจกต์ Supabase → วาง `supabase/schema.sql` ใน SQL Editor → ปิด Confirm email → ใส่ Project URL และ anon key ใน `config.js` → อัปโหลด `index.html`, `config.js`, `assets/` ขึ้นโฮสต์
เข้าสู่ระบบด้วยชื่อผู้ใช้ (ไม่ต้องมีอีเมลจริง) ผู้ดูแลสร้างบัญชีให้ใน Supabase และสร้างรหัสเชิญในหน้าหลังบ้าน คนแรกที่ล็อกอินจะเป็นเจ้าของระบบโดยอัตโนมัติ
